学习大厅配置交付说明
工程：D:\surgery-vr
日期：2026-11-12

一、现在可以怎样体验

打开 Assets/_Project/Scenes/学习大厅.unity。
首页可自由选择“认识病例”“站位与台高”“器械练习”“操作复盘”，也可以直接开始手术。
默认模式为“引导学习”；“自主练习”与其互斥。选择的模式和 CASE01 随正式会话进入小手术操作室。
目前两种模式的选择、传递和记录已经实现；具体手术提示的差异由后续手术流程控制器使用该模式决定。

建议检查路线：
1. 查看病例说明，使用上翻/下翻浏览，再返回主页。
2. 在“站位与台高”选择惯用手、到训练台前，按需要调整台高。
3. 打开“器械练习”，点击“开始 / 重试”。用镊子完成拿起、转向金色方向示意、双手交接、松手放回同名区域。
4. 可重试、回主页或直接进入手术；不存在练习完成门槛。
5. 在手术场景按右手 B 键打开暂停页，选择返回大厅；复盘会显示本次实际事件和未完成状态。
6. 正式手术流程将来确认完成后，调用完成接口，再返回大厅查看完成记录。

手柄：握持键近距抓取，松开释放；扳机点击 UI；左摇杆移动；右摇杆左右转向；按住右摇杆瞄准瞬移，松开执行；右手 B 暂停/继续。
UI 指针默认右手，可改成左手；正在持物或抓取的手不点击 UI；瞬移瞄准期间 UI 停用。
抓取、手指贴合、物体随动、释放与交接使用 AutoHand。没有加入远距离抓取或裸手追踪。

二、对象与功能对应

QuestRig/HallUI：共享手柄 UI 指针、EventSystem、暂停/返回/保存退出页、淡出遮罩、追踪中断与输入恢复。
LearningHallFeatures：大厅四个页面、模式选择、校准、练习、复盘和按钮绑定。
EntryAndReviewCanvas/InteractiveHallUI：可交互主面板；旧静态卡片保留在禁用的 LegacyStaticPanel 下。
Training_Scalpel：刀柄与刀片作为一个 AutoHand Grabbable，整体近距拿取。
Training_Forceps：AutoHand Grabbable，同时作为本轮四动作练习器械。
Training_Scissors：AutoHand Grabbable，整体近距拿取。当前不实现剪刀开合与剪切。
HallPlacementTargets：三件示教器械的同名归位区采用中空圆环（外径 24 cm、环宽约 7 mm），器械置于圆环中央；保留拿起与归位时的颜色反馈。稳定松手落位才确认，持物经过不计完成。旋转方向示意独立保留。
训练台 HallSurfaceCollider：简单承托碰撞体，防止动态器械穿桌。
Stand_Training / Spawn_Learning：训练台前站位与大厅入口重定位；不直接篡改追踪相机坐标。
CasePreviewCanvas：病例摘要；完整说明通过主面板查看。
柜体、推车、托盘、门、锐器盒和废物桶：维持展示用途。门不会因碰触而跳场景，示教器械不会被回收桶销毁。
RoomBakedReflection：每个场景一张低分辨率烘焙反射；共用材质已校正法线/颜色/遮蔽槽位。
LegacyDiagnostics_Preserved：保持禁用，原摆放与旧内容保留。

练习只记录尝试次数、完成次数和各动作完成情况，不生成正式手术成绩。
掉落后再换一只手拾起不算双手交接；复位不增加次数、不清空记录，也不拉走手中的器械。
台高调整每次 2.5 cm，范围 ±25 cm；持物或抓取动画进行中禁止调整。
