导入：
1. 在 surgery-vr 中选择 Assets > Import Package > Custom Package，选择本 unitypackage 并导入。
2. 当前 surgery-vr 已有必要的 Package Manager 依赖。迁移到其他工程时，需安装 Input System、OpenXR、XR Plugin Management、XR Legacy Input Helpers、URP、TextMeshPro 和 UGUI。
   本次使用的版本为 Input System 1.11.2、OpenXR 1.13.2、XR Management 4.5.4、Legacy Input Helpers 2.1.11、URP 14.0.11、TMP 3.0.7、UGUI 1.0.0。
3. Auto Hand 首次导入会按原插件逻辑创建 Grabbing、Grabbable、Hand、HandPlayer 四个层，并设置所需碰撞忽略关系。
   需要调节物理质量时，打开 Window > Autohand > Setup Window。本包保留作者的 Quest 质量级别 2。
4. Quest 控制器入口：Assets/AutoHand/Examples/Scenes/OpenXR/Prefabs/OpenXRAutoHandPlayer.prefab。
   测试场景中仅使用一套玩家 Rig、主相机和 AudioListener；该预制体与现有 QuestRig 的选择/衔接需在接入交互时处理。
5. 被抓物体需要 Collider、非运动学 Rigidbody、Autohand.Grabbable；固定器械抓姿使用 GrabbablePose / 手部抓姿工具。
6. Desktop Player 是旧键鼠演示，使用 Unity 旧 Input API；运行它需 Active Input Handling = Both。
   Quest/OpenXR 控制器入口使用新版 Input System，不需要为此开启旧输入。
